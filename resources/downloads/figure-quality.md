# Scientific figure quality checklist

A clear figure explains documented results; it must not manufacture evidence.

## Evidence
- [ ] Trace every panel to an analysis output and input dataset.
- [ ] Define sample size and unit of replication in the caption.
- [ ] Explain error bars, interval type and statistical annotation.
- [ ] State transformations, normalization and any filtering.
- [ ] Show comparable scales when panels are meant to be compared.
- [ ] Preserve meaningful zero/reference points and explain cropped axes.

## Readability
- [ ] Label axes with units and clear variable names.
- [ ] Check labels at intended publication size.
- [ ] Use readable colors and redundant shape/line cues.
- [ ] Avoid unnecessary 3D effects and decorative chart elements.
- [ ] Keep a consistent type and panel-label hierarchy.
- [ ] Prefer editable vector exports for suitable plots; check journal specifications.

## Export and review
- [ ] Check font embedding, clipping, image resolution and background.
- [ ] Inspect grayscale where relevant.
- [ ] Retain plotting code and an editable master.
- [ ] Remove participant identifiers and confidential filenames.
- [ ] Verify caption and plotted data together with a collaborator.
