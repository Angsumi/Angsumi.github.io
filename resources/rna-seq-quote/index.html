What to send for an RNA-seq analysis quote

Prepare a focused analysis conversation without sharing confidential files.

Start with the question

Describe the organism, biological comparison and why it matters. Name the assay and library preparation. Bulk RNA-seq, single-cell data and de novo transcriptomes require different reviews; do not assume one workflow fits all.

Describe the study design

List groups, biological replicates, paired subjects, batches and planned contrasts. Explain how samples were collected and which variables could affect interpretation. If group and batch coincide, more computation cannot recover a missing comparison.

Inventory the files

Say whether you have FASTQ reads, quantification files or a raw count matrix. Note approximate file sizes, reference assembly and annotation versions. Prepare a sample sheet whose identifiers match the files. Send file descriptions first, rather than confidential raw data.

Agree the deliverables

Discuss read-level QC when reads are available, design review, analysis tables, figures and interpretation. Include scripts, configuration, methods notes and rerun requirements in the scope. Identify compute charges and revision boundaries before starting.

Limitations

A quote is conditional on the input inventory and feasibility review. No analysis promises significance or publication. Missing metadata or unsuitable replication may narrow the questions that can be answered.
